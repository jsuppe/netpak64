08 — References & Bibliography

Consolidated bibliography for the entire architecture documentation. Inline citations throughout point here.

N64 platform documentation

  • N64brew Wiki — the actively maintained community hardware reference
    • Peripheral Interface — PI bus, domains, timing registers, DMA
    • Memory map — KSEG segments, PI address ranges
    • MIPS Interface — interrupt architecture
    • 64DD — disk drive, Randnet
    • ISViewer — debug channel precedent
  • NEC VR4300/VR4305/VR4310 User's Manual — CPU ISA, caches (16 KB I / 8 KB D, 16 B lines, write-back, no snooping), CP0/CAUSE interrupt bits. Widely mirrored.
  • 64dd.org — 64DD preservation project, hardware, Randnet service history, disk format

Homebrew ecosystem

  • libdragon — open-source N64 SDK
    • GitHub
    • DMA/cache helper semantics (8-byte alignment for dma_read/dma_write)
    • Cart-IRQ handler registration
  • N64brew — community (wiki, Discord, game jams)
  • N64-NetLib (buu342) — closest prior art: flashcart-USB homebrew networking with PC bridge and Java servers
  • UNFLoader (buu342) — standard USB flashcart loader/debug tool
  • SummerCart64 — open flashcart with 64DD-emulation mode
  • 64drive — dev flashcart with documented USB protocol

Emulators

  • ares
    • GitHub
    • Integration target; Node tree, cooperative scheduler, event queue, Homebrew Mode/ISViewer precedent
    • ISC-licensed
  • gopher64 — Rust N64 emulator with input-lockstep netplay
  • simple64 — input-lockstep netplay reference
  • cen64 — cycle-accurate C emulator; candidate second port
  • HailToDodongo's N64 dev fork of ares — developer-oriented fork; candidate second home

Networking design

  • Gaffer On Games (Glenn Fiedler) — the canonical game networking primer
    • UDP vs. TCP — rationale for fire-and-forget data
    • Packet fragmentation — why 1200 B MTU cap
    • Reliable ordered messages — sliding window pattern
  • GameNetworkingSockets (Valve) — industrial-scale reliable-over-UDP; the pattern our control plane and ch1 follow
  • RFC 768 — UDP specification
  • RFC 9000 §5.1 — QUIC connection IDs: connection identity decoupled from addresses (inspiration for token re-pinning)
  • RFC 5905 — NTPv4: conceptual basis for relay-anchored shared clock
  • RFC 9147 — DTLS 1.3; v2 hardening candidate
  • Noise Protocol Framework — v2 hardening candidate
  • End-to-End Arguments in System Design (Saltzer, Reed & Clark, 1984) — why ch1 reliability lives in the library, not the relay

Implementation stack

  • tokio — async Rust runtime for relay
  • Prometheus — metrics endpoint
  • PlantUML — diagram source format
  • C4-PlantUML — stdlib macros for architecture diagrams
  • C4 model (Simon Brown) — architecture documentation framework

Historical context

  • Randnet (64DD modem service, Japan 1999–2002) — established that networked N64 devices are period-authentic
  • SharkWire Online (N64 modem cartridge) — another network peripheral
  • Morita Shogi 64 (cartridge with built-in modem for networked shogi) — period-authentic example of game-level network features

Further reading

For deeper dives:

  • N64 hardware: N64brew wiki + Wikipedia N64 technical specs
  • Game networking: Gaffer On Games full archive + GameNetworkingSockets source
  • Security: Noise Protocol Framework + RFC 5246 (TLS 1.2) / RFC 8446 (TLS 1.3)
